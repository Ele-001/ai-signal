# 0.1.2 自动解除红灯

> 历史版本验收记录。0.1.3 已取消“无新进展自动红灯”，当前规则见 [QUIET-STATE-FIX.md](QUIET-STATE-FIX.md)。

修复日期：2026-10-26。

实际排查确认：旧版仍亮红灯的原因是监测保护中的「工作期间屏幕被锁定」，当前任务已运行，但旧提醒被设计为只能手动确认。

现在锁屏／暂停提醒会关联当时受影响的原任务及进展时间。桌面可用后，所有受影响原任务恢复进展或明确结束，自动解除该提醒。仍等待回答或没有新进展的任务保持提醒；无关任务的活动不能清除提醒。任务关联跨重启保存，兼容迁移 0.1.1 的旧提醒。「已检查」保留为兜底操作。

普通回答、任务运行／结束仍按已接入事件处理；其他任务仍待处理时，汇总红灯保持正确优先级。

测试涵盖：解锁但无进展不误清除、原任务恢复自动解除、原任务完成自动解除、无关任务不误清除、等待回答保持、跨重启关联、旧版提醒迁移、监测中断期间完成的恢复。

原生 26 项测试通过（另 1 项手动历史回放默认不运行）；前端 7 项与 Python 10 项在 0.1.1 已通过。本次原生及前端构建通过。完整物理锁屏／睡眠周期及 Windows 尚未实机复验。

实机结果：替换为 0.1.2 后，没有点击「已检查」，没有删除提醒或修改应用数据。应用先恢复旧红灯提醒，随后识别到原任务新进展，自动解除该提醒并切换为绿色运行状态。见 recovery-0.1.2.png。
