AI红路灯

0.1.6 · macOS · Apple Silicon（M 系列）

安装

  1. 如果旧版正在运行，先从菜单栏的交通灯图标选择“退出 AI红路灯”。
  2. 将安装盘中的 AI红路灯.app 拖入 Applications（应用程序）。更新时替换旧版本，设置仍保存在本机。
  3. 从“应用程序”打开 AI红路灯。安装后可推出此安装盘。

更名升级：新版名为 AI红路灯.app，不会自动覆盖旧名称的 AI Signal.app。请先退出旧版，安装新版后可将旧应用移到废纸篓，勿同时运行两版。本机连接和设置会继续保留。

需要 macOS 12.3 或更新版本、Apple Silicon 芯片。Intel Mac 和 Windows 不适用此安装包。日常使用无需安装开发工具。

首次打开

当前版本未使用 Apple 开发者证书签名，也未公证。若 macOS 提示无法验证开发者，请确认下载地址为下方项目的 GitHub 发布页，再按系统“隐私与安全性”中针对该应用的提示允许打开。无需关闭系统安全保护。

使用

拖动灯体调整位置，点击底部状态打开控制面板。“连接”中启用 Codex 后自动识别本机可读取的近期任务；“任务”中可查看原因和刷新任务。“外观”中可调整置顶、大小、透明度和声音。

🔴 红灯常亮需要处理已识别的问题，或实际锁屏、连接异常
🟡 黄灯规律双闪来源明确上报正在自动修复
🟢 绿灯不规则闪烁正在运行
🟢 绿灯低亮常亮来源报告本轮结束，不代表结果已经验收
全部熄灭没有已识别的活动任务

多任务按最高优先级汇总。无新消息不会仅因此转红。若本机待回答记录与你在 Codex 中看到的状态不符，可用“已处理”确认这次问题；新问题仍会提醒。它不会代替你回答或批准来源操作。

识别范围

兼容识别覆盖已连接、可读取、近 24 小时有更新的本机会话；不能保证覆盖云端、其他设备或所有 Codex Desktop 状态。Claude Code 需要在连接页配置并实际收到事件。

配置及手动任务保存在本机。升级时不用删除设置；单独删除安装盘不会删除已安装的应用。
