# 0.1.3：没有新消息不再误报红灯

取消原先的「连续 2 分钟无进展 → 红灯」规则，同时删除确认后的 2 分钟观察期逻辑。仅凭监测间隔超过 20 秒也不再转红；旧版这类暂停提醒自动丢弃。网络慢、耗时工具、后台任务或流式消息间隔本身不构成人工介入证据。

- 运行任务无新事件时继续绿闪；修复任务保留黄灯，不会按时间自动转红。
- 收到真实待回答、审批、锁屏或明确来源故障等证据，才按对应规则提醒。
- 收到恢复、完成、空闲或故障恢复事件后自动切换；静默状态不需要手动点击「已检查」。
- 旧版超时提醒在新监测周期自动移除，不需要人工确认。保留真实锁屏提醒与原任务恢复关联，避免撤销此前的锁屏保护。

回归测试模拟原生线程持续正常检查、同一个任务超过 20 分钟无新事件，验证 Running 和 Repairing 均不会产生红灯。另验证旧超时提醒无需确认即可清除，以及长时间静默后真正锁屏仍会触发提醒。

README、连接页说明、灯色总览图及红灯解除图同步更新。历史版本验收记录已明确标注旧规则失效。未知且未接入的审批无法靠消息间隔可靠判断，不声称能识别所有软件界面状态。

验证：28 项 Rust 回归测试、7 项前端测试及正式应用构建通过。20 分钟静默通过时间推进模拟验证，不等同于已等待 20 分钟实机复测。Windows 与完整物理锁屏周期未在本次重新实测。
