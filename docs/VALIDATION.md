## 桌面及预览验收

- 启动最终 Mac 应用，透明悬浮灯和系统控制窗口可显示。
- 在真实桌面应用中新增手动任务、切换待处理状态并删除，均成功。
- 已验证真实本机 HTTP 事件能够进入桌面列表，并在手动红灯任务存在时保持红灯优先；移除红灯任务后显示运行状态。
- 浏览器核对了绿灯不规则短闪、黄灯规律双闪、红灯外围呼吸、完成确认闪和空闲无动画的实际 CSS 动画。
- 关闭动态灯效后动画停止；刷新页面后设置仍保留。两种灯体可切换。系统减少动态效果时采用静态显示。
- 窗口大小、置顶、声音、缩放、透明度和托盘已有实现；本轮没有逐项重复所有系统窗口操作。位置不持久化。

## Codex 真实连接

在桌面版连接页点击 Codex 的「连接」后，应用自动发现了 2 个当时正在运行的本机会话，任务进入列表，来源显示为「Codex · 本机识别」。未手工录入这些任务，也未修改 Codex 配置。随后重新检查最终应用，已自动识别 3 个运行会话；重启后连接设置仍保留。

当前安装的 Codex CLI 为 0.164.0-alpha.11.1。此识别依赖本地会话生命周期记录与标题索引，属于兼容方案，不能保证覆盖全部 Codex Desktop 会话。读取范围、更新窗口和大文件边界详见 INTEGRATION.md。

Codex 官方 Hooks 的目标客户端自动流仍未通过安装、信任 Hooks 的方式单独实测。它可以补充本机识别无法可靠判断的审批等状态，但需要用户配置与信任。

## Claude Code 的验证边界

当前电脑没有 Claude Code 配置目录，界面正确显示先运行一次的提示，没有把它标成已连接。

已经验证原生助手的输入映射、认证投递，以及临时测试目录中的配置合并、备份、重复连接、断开保留其他设置和损坏文件保护。没有改动真实 Claude 用户配置，也没有验证真实 Claude Code 客户端自动事件流。安装客户端并完成工作区信任后，需收到真实任务事件，才可将该环境标成已验证联动。

## 发布与平台限制

交付包为 Apple Silicon arm64，采用本地临时签名，没有 Apple Developer ID 签名或公证。没有制作已签名的公开发行包。

Windows 源码路径、窗口、托盘、声音、配置及原生助手均已实现，但没有 Windows 实机构建和运行记录。开机启动未实现。应用退出时不再接收事件，事件不排队重放。
