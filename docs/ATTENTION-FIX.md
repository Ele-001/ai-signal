# 0.1.1 红灯漏报修复验收

> 历史版本验收记录。0.1.3 已取消“无新进展自动红灯”，当前规则见 [QUIET-STATE-FIX.md](QUIET-STATE-FIX.md)。

日期：2026-10-26。环境：macOS 26.3，Apple Silicon。

## 修复内容

1. 异步用户提问记录纳入状态解析。`accepted: true` 只表示已提交，不能视为用户已答；本轮结束后仍红灯。多问题逐项解除；拒绝提交与新的普通用户请求不会遗留旧的等待状态。
2. 明确工具锁屏错误转为待处理；普通进度和完成事件不能覆盖仍存在的待处理证据。
3. 独立原生保护线程检测锁屏、桌面状态读取失败、超过 20 秒的监测中断、来源故障与运行任务 2 分钟无新进展。保护提醒独立于普通任务，不受模拟和其他绿色任务覆盖。
4. 锁屏／中断提醒解锁后保持，需检查确认，且跨应用重启保存。连接故障必须实际恢复才可解除。超时确认仅给予 2 分钟观察期。
5. 前端每 5 秒补取状态，超过 3 秒未能读取即显示内部连接故障红灯，避免遗漏事件后一直绿灯。
6. 扫描时间窗由 15 分钟扩大至 24 小时；使用文件真实修改时间计算无进展，不会把重新扫描当作新进展。目录读取失败和超过 32 份记录的范围限制明确红灯提示。

## 自动及回放测试

- 前端 7 项、Rust 22 项、Python 10 项，共 39 项通过。
- 另手动执行 1 项真实本地历史回放测试：用户截图对应任务在异步提问已受理、本轮已结束但用户尚未回答时保持 Attention；真实回答到达后清除等待。历史内容没有复制进源码或交付包。
- Rust 回归包括：锁屏转红、解锁后保留、禁止锁屏时确认、空闲锁屏不误报、开始工作时已锁屏、超时与恢复、确认后再次超时、暂停与故障恢复、部分回答、提交失败、普通事件不能覆盖等待。
- 真实 macOS 会话状态读取通过。系统会话字段属于兼容读取，保留无进展兜底。

## 桌面实测

- 运行已构建的 0.1.1 应用，实际识别到「响应式官网设计方案」正在等待用户回答，任务为 Attention，汇总为红灯。
- 在实际应用发送临时任务「监测回归测试」，等待超过 2 分钟无事件，实际出现红灯「状态待确认」。发送完成事件后，该超时提醒自动解除，而其他真实待处理任务继续保持红灯。已移除临时测试任务。
- 该真实任务后续收到新用户消息／恢复工作时，待回答状态解除，未永久卡在红灯。

没有主动锁定用户电脑或让电脑睡眠；完整的物理锁屏、解锁、睡眠周期未实测。相关状态转换已自动测试，当前系统读取已验证。Windows 未实机验证，Claude Code 真实客户端仍未安装测试。普通窗口不能显示在系统锁屏界面上，解锁后通过保留提醒避免漏看。

未接入来源、远程会话、扫描范围外的会话及无法读取的审批不能保证即时识别；缺少进展的运行任务采用 2 分钟兜底。耗时工具可能触发保守提醒。应用完全退出时无法发出提示，不应视为监测仍在工作。
